Quick Start:

CLI:
  python -m RosterIQ.tests.run_all_tests

Python:
  from RosterIQ.tests.run_all_tests import TestRunner
  runner = TestRunner()
  report = runner.run_all(verbose=True)

FastAPI:
  GET /api/v1/admin/test-report
  POST /api/v1/admin/run-tests
  GET /api/v1/admin/test-coverage

Key Classes & Methods:

TestRunner:
  - discover_tests(test_dir="tests") -> List[Path]
  - _extract_test_functions(file_path: Path) -> List[str]
  - _run_single_test(test_func, test_name: str) -> TestResult
  - run_all(verbose: bool = False) -> TestRunReport
  - generate_coverage_report() -> CoverageReport
  - generate_report(format: str = "text") -> str

Data Classes:
  - TestResult(name, status, duration_ms, error_message, ...)
  - FileResult(file_path, test_count, passed, failed, ...)
  - TestRunReport(total, passed, failed, errors, ...)
  - CoverageReport(total_services, covered_services, ...)

FastAPI Routes:
  - GET /api/v1/admin/test-report -> TestResultResponse
  - POST /api/v1/admin/run-tests -> TestRunResponse
  - GET /api/v1/admin/test-coverage -> CoverageResponse
